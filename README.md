# Dark Souls 3 Build Tool

## 概要
ダークソウル3のキャラクターのステータスや装備構成を管理するWebアプリケーションです。

ゲーム内のステータスや装備を入力することで、ビルドの構成や装備重量などを確認できます。

## 使用技術
- Java 25
- Spring Boot
- Gradle
- HTML
- CSS
- JavaScript
- CSV

## 主な機能
- キャラクターのステータス入力
- ステータスに基づく素性候補の判定
- 武器の選択と必要能力値の確認
- 防具・指輪の選択
- 武器・防具・指輪の装備重量の集計
- 最大装備重量に対する重量割合の計算
- 最大HP・スタミナの計算

## 開発での経験
- JavaとSpring Bootを使用したバックエンド開発
- APIを利用した画面とサーバー間のデータ連携
- JavaScriptによる画面操作・計算処理
- CSVファイルを利用した武器・防具などのデータ管理
- 機能追加や不具合修正
